# Lista de Exercícios -- Progamação Orientada a Objetos (POO)

Abaixo, segue 3 ativividades para serem desenvolvidas utilizando a plataforma [tryjs.app](https://tryjs.app/).

Após concluir cada atividade, o código deve ser salvo em um repositório público no github nomeado como `programacao_orientada_a_objetos`

------------------------------------------------------------------------

## 1) Carro -> `carro.js`

Nessa atividade, você deverá realizar as seguinte etapas:

1. Crie uma classe chamada **Carro**, usando um *constructor* adicione os atributos: *marca* e *velocidade*;
2. Crie o método `acelerar()` que aumenta a velocidade;
3. Instancie 2 (dois) objetos diferentes da classe Carro;

> **Tip:** O método pode conter operações matemáticas além da exibição de um `console.log`

------------------------------------------------------------------------

## 2) Jogador (Parte 1) -> `jogador.js`

Nessa atividade, você deverá realizar as seguinte etapas:

1. Crie uma classe **Jogador**, usando um *constructor* adicione os atributos: *nome* e *pontuacao*;
2. Adicione o método `ganharPontos()`;
3. Instancie 3 (três) objetos usando a classe Jogador;

> **Tip:** Adicione ao método um parâmetro para ser informado quantos pontos serão adicionados

------------------------------------------------------------------------

## 3) Jogador (Parte 2) -> `jogador.js`

Nessa atividade, você irá complementar o código já desenvolvido na atividade anterior.

1. Crie uma classe **Inimigo**, usando um *constructor* adicione os atributos: *vida* e *dano*;
2. Adicione o método `receberDano()`
3. Crie um sistema simples de ataque entre jogador e inimigo.

> **Tip:** Crie também uma classe arma que poderá ser usado pelos personagens
