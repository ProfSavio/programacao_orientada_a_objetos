# Criar repositório

1. Dentro do seu perfil vá em "Repositories"
2. Selecione a opção de "New"
3. Informe o nome do seu repositório
4. Caso queira, informe uma descrição para o seu repositório, esse dado é opcional
5. Mantenha a visibilidade como **Public**
6. Adicione um `.gitignore` como **Node**
7. Clique em "Create repository"

# Abrir Codespaces

1. Acesse o seu repositório
2. Vá em "Code"
3. Acesse a sessão "Codespaces"
4. Inicie um novo codespace

# Commitar e enviar para repositório remoto

Abra o terminal e execute os seguintes códigos:
```
git status
git add .
git status
git commit -m "[escreva aqui a 'legenda' da sua 'foto']"
git status
git push
```
